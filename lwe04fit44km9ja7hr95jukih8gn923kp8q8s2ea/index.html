02いまどこにいるのか

建物ができるまでには、構想 → 計画 → 設計 → 工事という段階があります。市の「プロセス図」によると、設計までは終わっていました。2026年9月、市は方針を見直すこととしました。

どこまで戻るのか。基本設計までです。市は「方針の見直しにより基本設計からやり直すことを想定」と説明しています。基本構想と基本計画は策定済みで、市が2026年9月15日に示した最短の日程の試案も、いまの基本計画に基づいて進めると仮定したものです。

  1. 基本構想平成22年度 策定
  2. 基本計画平成24年度 策定
  3. 基本設計令和元年度 完了▲ ここからやり直す想定
  4. 実施設計令和6年度 完了
  5. 建設工事未着手
  6. オープン未定

これからの予定（市が示しているもの）

  1. 2027年3月令和9年3月新しい方針を策定市の公式ページによる予定
  2. そのあと基本設計からやり直し市の現時点の想定
  3. 2030年7月令和12年7月着工最短の場合の試案
  4. 2033年10月令和15年10月供用開始最短の場合の試案

着工と供用開始は、設計と施工を一括で発注する方式で進めると仮定した、最短の場合の試案です。市の資料は、これより48か月延びる可能性があり、市民参加の手続や市議会の協議の状況などによってはさらに延びる可能性があると注記しています。市の公式ページは、着工は令和12年度以降になる見込みとしています。2026年10月22日の委員会で市が示した考え方（建設工事費約170億円を目安に、令和12年度着工・令和15年度竣工を想定）は、07 年表の同じ日の項目にあります（非公式の書き起こしによる要旨）。

この内訳の読み方。資料が挙げる増の要因は合計で約38.4億円、減の要因は合計で約2.7億円です（どちらも資料の数字を足したもの）。最も大きいのは、2023年5月の「建築物価上昇による増」約24.6億円です。資料によると、このときの115.3億円は、2021年11月の90.7億円に建築費の指数（過去1年の平均）の上昇率を反映して、工事の着工を予定していた令和7年1月の時点の額として算出したものです。2021年9月の「初回積算時の増」について、資料は、設計の詳細が決まっていない段階の概算から、詳細が決まった段階の積算になり、精度が高まったことによると注記しています。VE・CDは、資料に説明はありませんが、一般に、機能を保ちながら費用を下げる見直しを指す言葉です。資料の数字は0.1億円単位のため、前の時点に要因を足し引きした額と、次の時点の額が0.1億円ずれるところが1か所あります。

市の説明

  • 工事費は「建設物価高騰等の影響により増額しています」。
  • 2回の入札中止のあと、市は当時の状況を、建設資材や人件費の高騰で工事費が高騰し、建設市場は繁忙期で「全国的に公共工事の入札不調が増加」していると説明した。
  • そのうえで、設計の見直し・現行案・凍結の計9パターンを比べ、現行案を「全選択肢の中で最も早く建設可能」、デメリットを「財政見通しの懸念」と整理。「財政見通しは成立すると判断し、現設計により3回目の入札を行うことにしました」と説明していた。
  • 2026年9月、240億円程度まで上昇することも想定されるとの調査結果を受けて、現設計での3回目の入札を断念した。
  • 2026年10月22日の特別委員会で、建設工事費約170億円を基礎に施設の内容を検討し、最短で令和12年度着工・令和15年度竣工を想定する考え方を示した。根拠は、今後の実施計画と財政見通しの中で示すとしている。企画政策課長はこの額を現時点での上限の目安と説明し、市長は、あくまで目安で明確な金額ではないと述べた（非公式の書き起こしによる要旨。年表を参照）。

04借りている庁舎に、いくら払ってきたか

第二庁舎は、新庁舎ができるまでの仮庁舎として、1993年度に借り始めた建物です。当初の覚書は10年間でしたが、いまも借りています。

市が挙げる、早期建設を目指す理由（4つ）。借りている庁舎の解消は、1つ目の理由の中で触れられています。
  1. 現庁舎の老朽化・耐震性能・バリアフリー対応、防災拠点整備等の課題
  2. 閉館した旧福祉会館機能の早期回復
  3. 事業延伸による機会の損失
  4. 近年の建設物価の動向

  4. 市は2027年3月に新しい方針を出すとしています。事業費だけでなく、完成後の維持費や学校の改修との両立まで含めた見通しを、市民に分かる形で示すことを求めたいと考えます。
